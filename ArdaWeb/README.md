# ArdaWeb

ArdaWeb, Mersin merkezli işletmeler için kurumsal web tasarım, QR menü, randevu sistemi, restoran çözümleri ve işletmeye özel yazılım hizmetlerini tanıtan tek sayfalık ajans sitesidir.

## Dosya Yapısı

- `index.html` - SEO uyumlu tek sayfalık kurumsal ajans sitesi
- `style.css` - Beyaz ağırlıklı modern SaaS tasarım, responsive kart sistemi ve dashboard mockup
- `script.js` - Sticky header efekti, mobil menü, reveal animasyonları ve form başarı mesajı
- `README.md` - Proje açıklaması ve çalıştırma adımları

## Nasıl Çalıştırılır?

Kurulum gerektirmez. Saf HTML, CSS ve JavaScript ile hazırlanmıştır.

1. `C:\Users\LENOVO\Desktop\yeni arda web\ArdaWeb` klasörünü açın.
2. `index.html` dosyasına çift tıklayın.
3. Site tarayıcıda açılacaktır.

## SEO Çalışmaları

- SEO uyumlu `title` etiketi eklendi.
- Meta description ve keywords eklendi.
- Tek H1 kullanıldı.
- H2 başlık yapısı düzenlendi.
- Mersin web tasarım, Mersin yazılım şirketi, QR menü sistemi, randevu sistemi ve SEO uyumlu web tasarım odaklı içerikler eklendi.
- LocalBusiness JSON-LD schema eklendi.
- Ağır görsel kullanılmadı; dashboard ve görsel alanlar CSS/SVG ile hafif tutuldu.
- Mobil uyumlu responsive yapı kuruldu.

## Not

Delivera Express, Entegrasyon POS, Berber Randevu Sistemi ve Haber Web yalnızca isim ve açıklama olarak gösterilmiştir. Bu projelerin dosyalarına dokunulmamıştır.
